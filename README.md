# citibikeavailability
Modeling NYC citibike availability through Markov Chains

## Local Python environment

Use Python 3.12 to create and activate a project-local virtual environment:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

In VS Code, select `.venv/bin/python` as the Python interpreter and notebook kernel.
